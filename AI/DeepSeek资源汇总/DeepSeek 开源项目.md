## DeepSeek 開源專案

## 官方開源

| 專案名稱          | 專案連結                                         | 簡介                                                         |
| ----------------- | ------------------------------------------------ | ------------------------------------------------------------ |
| DeepSeek-R1       | https://github.com/deepseek-ai/DeepSeek-R1       | DeepSeek的旗艦語言模型，提供高質量的響應，支援多種自然語言處理任務。 |
| DeepSeek-V3       | https://github.com/deepseek-ai/DeepSeek-V3       | DeepSeek的第三個版本，採用創新的混合專家架構（MoE），支援多模態搜尋。 |
| DeepSeek-V2       | https://github.com/deepseek-ai/DeepSeek-V2       | 一款強大、經濟高效的專家混合語言模型                         |
| DeepSeek-Coder-V2 | https://github.com/deepseek-ai/DeepSeek-Coder-V2 | 採用混合專家（Mixture-of-Experts，MoE）架構，突破閉源模型在程式碼智慧中的壁壘 |
| DeepSeek-Coder    | https://github.com/deepseek-ai/DeepSeek-Coder    | 用於輔助程式碼編寫的AI工具，支援多種程式語言。                 |
| DeepSeek-LLM      | https://github.com/deepseek-ai/DeepSeek-LLM      | 提供準確可靠答案的綜合語言模型。                             |
| Janus             | https://github.com/deepseek-ai/Janus             | 統一的多模態理解與生成模型                                   |
| DreamCraft3D      | https://github.com/deepseek-ai/DreamCraft3D      | 基於引導擴散先驗的分層3D生成模型的官方實現                   |
| DeepSeek-Math     | https://github.com/deepseek-ai/DeepSeek-Math     | 透過增強模型的數學理解和推理能力，突破了傳統語言模型在數學領域的限制，能夠處理更復雜的數學推理任務，如符號計算、定理證明等 |
| DeepSeek-MoE      | https://github.com/deepseek-ai/DeepSeek-MoE      | 創新的混合專家架構模型，支援高效推理。                       |
| DeepSeek-VL2      | https://github.com/deepseek-ai/DeepSeek-VL2      | 用於先進多模態理解的專家混合視覺-語言模型                    |
| DeepSeek-VL       | https://github.com/deepseek-ai/DeepSeek-VL       | 透過深度學習技術增強視覺和語言的融合，解決複雜的視覺-語言任務 |
