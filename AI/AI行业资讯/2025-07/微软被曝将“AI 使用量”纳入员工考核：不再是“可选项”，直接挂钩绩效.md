# 微軟被曝將“AI 使用量”納入員工考核：不再是“可選項”，直接掛鉤績效

本文轉載自： [微軟被曝將“AI 使用量”納入員工考核：不再是“可選項”，直接掛鉤績效](https://www.ithome.com/0/864/820.htm)

[IT之家](https://www.ithome.com/) 6 月 30 日訊息，據《商業內幕》27 日報道，微軟開發者工具部門總裁 Julia Liuson 最近發出內部郵件，要求各級主管在評估員工績效時，將其使用 GitHub Copilot 等內部 AI 工具的情況納入考量。

Liuson 表示，AI 已**成為微軟日常工作的核心**，就像團隊協作、資料導向思維和溝通能力一樣，使用 AI 不再是選擇題，而是每個崗位的基本要求。她指出，員工是否有效使用 AI，應該被納入對其**整體表現和影響力**的全面評估之中。

![](https://pic.code-nav.cn/post_picture/1610518142000300034/iga0SA9I8wY3D62O.webp "微軟被曝將“AI 使用量”納入員工考核：不再是“可選項”，直接掛鉤績效")

知情人士透露，微軟各團隊的績效考核標準不盡相同，目前已有部分團隊考慮在下一個財年正式將 AI 工具使用情況作為績效指標之一。

另據兩位瞭解內情的人士稱，這一改變旨在應對**微軟內部 Copilot 服務推廣緩慢**的問題。微軟希望提升整體使用率，也希望產品開發人員更深入理解自家 AI 工具的運作方式。

目前 GitHub Copilot 正面臨 Cursor 等 AI 程式設計服務的競爭壓力。微軟允許員工使用**符合安全規範的部分第三方工具**，知情人士稱，Replit 就是其中之一。

IT之家注意到，巴克萊銀行近期的一份報告顯示，Cursor 在開發者市場的某個關鍵領域已超過 GitHub Copilot。

而 AI 程式設計工具間的競爭，也影響到微軟與 OpenAI 的重要合作關係重談程序。一位訊息人士透露，OpenAI 正考慮收購 Cursor 的競爭對手 Windsurf，但由於與微軟現有協議的條款，微軟可獲取 Windsurf 的智慧財產權，這讓 OpenAI 和 Windsurf 均感到不安。
