# 騰訊 CodeBuddy IDE 程式碼助手國內版公測，DeepSeek-V3.1 最新模型免費用

本文轉載自： [騰訊 CodeBuddy IDE 程式碼助手國內版公測，DeepSeek-V3.1 最新模型免費用](https://www.ithome.com/0/877/258.htm)

感謝IT之家網友 [動感超人233](https://m.ithome.com/html/app/open.html?url=ithome%3A%2F%2Fuserpage%3Fid%3D1847841) 的線索投遞！

[IT之家](https://www.ithome.com/) 8 月 22 日訊息，騰訊雲程式碼助手 CodeBuddy 昨晚宣佈，CodeBuddy IDE 國內版正式開放公測，無需邀請碼即可免費使用最新的 DeepSeek-V3.1 模型。

![](https://pic.code-nav.cn/post_picture/1610518142000300034/Vc4LwWz5fegMuy4F.webp "騰訊 CodeBuddy IDE 程式碼助手國內版公測，DeepSeek-V3.1 最新模型免費用")

IT之家附下載地址（Beta 版）：[Tencent Cloud Code Assistant CodeBuddy – AI Code Editor](https://copilot.tencent.com/ide/)

官方表示，CodeBuddy 可以真正實現**一個人變成一整個開發團隊**的體驗，支援產品設計、研發編碼、部署驗證等功能。

* 產品設計：**一句話生成可落地互動原型**，支援上傳圖片及區域性調優。

* 研發編碼：內建 Figma，**設計稿秒變可維護原始碼**。同時，內建騰訊雲開發 CloudBase、EdgeOne Pages 及 Supabase，幫助開發者自動配置資料庫、使用者認證等後端服務，快速構建、部署站點和無伺服器應用。

* 部署驗證：透過 CloudStudio 一鍵部署至沙箱環境，並生成可分享連結。
