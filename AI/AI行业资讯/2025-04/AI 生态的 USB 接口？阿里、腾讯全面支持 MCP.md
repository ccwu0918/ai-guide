## AI 生態的 USB 介面？阿里、騰訊全面支援 MCP

成為未來 AI 生態的“標準 USB 介面”

MCP 被認為是未來 AI 生態的“標準 USB 介面”，OpenAl、谷歌、微軟和亞馬遜等均已支援。

阿里雲百鍊上線業界首個全生命週期 MCP 服務，無需使用者管理資源、開發部署、工程運維等工作，5 分鐘即可快速搭建一個連線 MCP 服務的 Agent（智慧體）。騰訊雲也迅速跟進，正式釋出“AI 開發套件”，支援 MCP 外掛託管服務，幫助開發者最快 5 分鐘搭建業務型 AI Agent。《科創板日報》注意到，即將在 4 月 25 日舉行的 Create2025 百度 AI 開發者大會上，MCP 生態也成為重要議題之一。

過去一個月，國外巨頭如 OpenAl、谷歌、微軟和亞馬遜也陸續宣佈支援或正在深度整合 MCP 協議。

中信建投認為，在 AI Agent 中，MCP 相較於傳統 Function Calling 外部工具的呼叫方式，透過主機、伺服器和客戶端的解耦，大幅降低重複開發成本，同時提升了各類 AI 工具的互聯互通能力，亦為全球復現 Manus 的關鍵技術。隨著頭部公司的加速支援，MCP 生態邊界有望進一步拓展，加速 AI 產業發展。

當前 MCP 協議仍處在發展早期階段，生態不健全、工具鏈不完整、資料質量不能保證等等，是其面臨的主要挑戰。

## **成為未來 AI 生態的“標準 USB 介面”**

MCP（Modular Context Protocol）是給多智慧體系統使用的上下文協議，讓不同 Al Agent 聽得懂彼此的“工作語言”。過去，大模型想呼叫導航、訂酒店等這些功能，得程式設計師一個個寫程式碼對接，現在只要符合 MCP 標準，所有工具都能即插即用。

阿里雲智慧集團資深副總裁劉偉光表示， **MCP 是今天公認的業界標準，有望加速 AI 應用爆發的最後一公里的連線。**

“在 MCP 之前有很多人嘗試過函式呼叫、提示詞工程、外掛等方式，今天 MCP 透過統一標準介面， **類似於今天電腦手機當中看到 USB-C、Tap C 介面，這樣一種標準介面降低大模型和外部系統的整合門檻。“**

映雲科技市場與開發者社群總監顧鈞表示，MCP 的價值在於標準化了模型和其他元件之間的訪問介面，簡化了之前複雜的構建 Agent 的框架。

相比最初 AI 智慧體的單打獨鬥，現在的 AI 智慧體已經開始成為“一個小團隊”，負責行程規劃的、負責訂票的、負責客服聯絡的….….每個 Agent 各司其職， **而 MCP 有望成為未來 AI 生態的標準化協議，負責串起每個 Agent 的意圖、狀態、任務和環境。** 正如當年智慧手機靠“應用商店”引爆生態，MCP 或許就是 AI 時代的生態鑰匙。

快思慢想研究院院長田豐向《科創板日報》介紹，“MCP 就好比一條高速公路，原來大家用 API 連線 APP，現在用 MCP 來連線 Agent，實現快速呼叫、資料互動。比如，開車時想知道周圍有哪些好吃的，餓了麼、大眾點評 MCP 服務就可以推薦了。在開車沿途過程中，各種衣食住行都可以給使用者推薦。如果透過 MCP 更好地呼叫跨領域多智慧體協作，來完成使用者的複雜任務，實現智慧體任務流之間的無縫銜接，那麼對於使用者體驗將有很大的提升。”

## **阿里、騰訊等支援 MCP 國內協議標準開啟**

巨頭們自然不會錯過這一 AI 生態佈局。此前，OpenAl、谷歌、微軟和亞馬遜等國外企業已經陸續宣佈支援或正在深度整合 MCP 協議。OpenAI 於 3 月 27 日官宣 Agents SDK 加入 MCP 服務協議，後續 ChatGPT 桌面應用和 Responses API 也將快速支援。

國內廠商也開始跟進。昨日，阿里雲百鍊宣佈全面支援 MCP 服務部署與呼叫，首批上線了高德、無影、Fetch、Notion 等 50 多款阿里巴巴集團和三方 MCP 服務。

騰訊雲緊隨其後宣佈支援 MCP。有業內分析認為，一旦 MCP 能在微信生態中落地，基於微信小程式、企業微信、騰訊會議等平臺的 Al Agent 會獲得巨大的可用空間。這對開發者來說，是非常現實的利好。

此外，百度地圖、高德地圖、騰訊地圖，以及螞蟻集團旗下 OceanBase 資料庫等應用也已宣佈支援 MCP 介面。

一位浙江大學 AI 研究學者表示，隨著國內 MCP 協議標準開啟，有望推動各類 Agent 炸場，未來甚至人人都可以是程式設計師。

開放傳神（OpenCSG）創始人陳冉向《科創板日報》分析，MCP 是 AI Agent 的中間態，其推動 AI agent 爆發的作用無需質疑，而未來終極形態則是 Native Agent（原生智慧體）。

《科創板日報》獲悉，阿里雲已在推進 AI Agent Store 的生態建設。“站在 2025 年 AI Agent 爆發元年，不僅屬於技術突破，更屬於開放、協作和共享生態，我們追求的一定不是單純的模型強國，而是未來的更為豐富的 AI 應用強國。”阿里雲智慧集團資深副總裁劉偉光稱。

田豐看好騰訊和阿里系既有的業務生態所形成的智慧體家族，在 MCP 協議的推動下有望發揮更大的價值。“以往不同廠家的移動網際網路 APP 之間是有巨大的壁壘，在單一廠家生態範圍內透過 MCP 修路，這些 APP 能變為一種 AI 智慧體的管家組合，然後開放給阿里雲上的 Agent 開發者。”

## **MCP 協議仍處在發展早期**

雖然阿里、騰訊等巨頭的入局為其注入了動力，但 MCP 協議仍處在發展早期階段。

“生態不健全，工具鏈不完整，模型成本還過高，資料質量不能保證等等，是目前 MCP 協議發展的挑戰。”陳冉提到。

顧鈞認為， **核心還是效果，能否滿足業務需求。“資料庫這些基礎軟體支援 MCP 協議，會比較簡單，但如果是現有的業務系統，千頭萬緒想要支援不容易。”**

另有，IT 業內人士認為，網際網路的封閉生態，難以讓 MCP 協議發揮預想的效應。“各個網際網路企業會在內部生態裡實現打通，但對外該封閉還是封閉。而 MCP 協議的初衷是在開放資料的預設場景下推出的，如果不是這樣的，那麼其對 AI 智慧體生態打造的作用會很有限。”

田豐也表示，MCP 生態的開放程度非常重要，才能在上面長出新應用。“因為就算有了高速公路，但如果這條路上有一堆關卡要收昂貴的過路費，那麼開發者是玩不起的，他們是從 0 到 1 在做創新。”

總而言之，MCP 協議要成為真正的行業標準，除了協議本身的相容性和安全性問題，還需要生態的進一步成熟。這也是 MCP 能否走遠的關鍵。
