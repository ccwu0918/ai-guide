# 點贊收藏！DeepSeek在GitHub星標量已超OpenAI

國產大模型深度求索（DeepSeek）正在與大洋彼岸的人工智慧巨頭OpenAI“掰手腕”。

2月7日，據全球最大程式碼託管平臺GitHub顯示，在兩個月內，DeepSeek的Star量（星標）已經超過了OpenAI。截至18時，DeepSeek旗下熱度最高的專案DeepSeek-V3大模型Star量達到7.82萬，超越同平臺中OpenAI最熱門專案（6.93萬）。Meta旗下的llama星標量最高超過5.7萬，阿里旗下的Qwen 2.5星標量超1.4萬。

據官方介紹，“星標”意味著被使用者收藏，許多專案的評級取決於擁有的星標數量，“標星操作便於以後再次找到倉庫或主題。可以對儲存庫和主題標星以跟蹤感興趣的專案，並在訊息饋送中發現相關內容。”Github如此解釋了標星的意義。

不過，有業內人士向澎湃新聞記者分析，由於DeepSeek是開源大模型，OpenAI未開源，最熱門的是API案例和使用指南，在一定程度上會影響星標數量。星標數量不能完全代表兩個大模型在能力上的區別，但是代表了AI行業整體的認可程度。

據研究公司SimilarWeb估計，在短短一週內，DeepSeek網站的使用者數量就超過了谷歌的Gemini聊天AI，後者已經存在了近兩年。DeepSeek.com上週二的訪問量達到了創紀錄的4900萬次，比前一週增長了614%。

DeepSeek因其開源、低成本等優勢，成為近期最火熱的話題之一。資料顯示，DeepSeek應用上線20天，日活就突破了2000萬。

據公開資料顯示，DeepSeek旗下開放式V3模型訓練成本為550萬美元，明顯低於美國類似解決方案的成本。同時，它的能力與ChatGPT的功能相當，但有一個重要的區別：該模型可以免費下載並在本地伺服器上執行，也因此廣受企業和組織關注。

由於DeepSeek的強大能力，引發全球性震動，尤其是引發美國科技公司集體性焦慮。據美國全國廣播公司(NBC)報道，美國總統特朗普當地時間1月27日在佛羅里達州邁阿密舉行的共和黨會議上表示，中國人工智慧初創公司DeepSeek的AI技術給美國科技企業敲響“警鐘”，美國公司“需要專注於競爭以贏得勝利”。

海外科技巨頭正在加速追趕，密集加快上新速度。當地時間2月5日，谷歌旗下AI大模型Gemini系列全面上新，包括正式版Gemini 2.0 Flash、Gemini 2.0 Flash-Lite以及新一代旗艦大模型Gemini 2.0 Pro實驗版，並在Gemini App中推出了其推理模型Gemini 2.0 Flash Thinking實驗版，作為對近期走紅的推理模型DeepSeek-R1和OpenAI旗下模型o3-mini的回應。

同樣是在2月5日，在谷歌Gemini模型上新的幾小時後，OpenAI宣佈ChatGPT Search向所有人開放，無需註冊。目前，就同谷歌搜尋一樣，來到OpenAI官網首頁就可以直接使用搜尋功能。這對於谷歌而言無疑是一次巨大的衝擊，不少網友調侃道“谷歌再見”，也有網友表示“感恩DeepSeek”。

2月6日，外交部發言人郭嘉昆主持例行記者會。韓聯社記者提問，據報道，韓國的一些政府部門遮蔽對DeepSeek的訪問，義大利、澳大利亞、印度、美國、日本等國家也傳出禁止或限制使用DeepSeek的訊息，一些企業也遮蔽了訪問。對此，中方如何看待？

“我注意到有關情況，”郭嘉昆強調，中國政府高度重視並依法保護資料隱私和安全，從來沒有也不會要求企業或個人以違法的形式採集或儲存資料。中方一貫反對泛化國家安全概念，將經貿科技問題政治化的做法，同時中方也將堅定維護中國企業的合法權益。

在2月初，華為雲、騰訊雲、阿里雲、百度智慧雲等國內主流雲平臺紛紛宣佈上線DeepSeek旗下的R1大模型。海外各大雲廠商和晶片廠商在更早之前就已紛紛宣佈上線DeepSeek-R1模型。北京時間1月31日，英偉達宣佈DeepSeek-R1模型登陸NVIDIA NIM。據介紹，在單個英偉達HGX H200系統上，完整版DeepSeek-R1 671B的處理速度可達每秒3872 Token。英偉達競爭對手AMD也宣佈，已將新的DeepSeek-V3模型整合到Instinct MI300X GPU上，針對Al推理進行了最佳化。
