## 開發技巧

1）推薦用 Linux 或 Mac 系統（或者 Windows 裝 WSL），執行終端命令更方便 => 或者在上下文中告訴 AI：使用 Windows 系統的終端命令

2）有的時候 AI 會因為缺少上下文資訊導致陷入迴圈，一旦發現迴圈，建議人工介入（可以問下別的 AI）

3）建議大家建立新專案時，用最複雜的（最高階的）推理模型

4）注意如果檔案沒有自動儲存，可以手動儲存一下（在檔案管理器中檢查）。或者在 File 選項中設定自動儲存

5）建議利用 Git 對程式碼進行管理，防止 AI 生成程式碼有誤時，因為編輯器錯誤導致老程式碼無法復原

6）如果單一的大模型無法正常完成工作，可以利用其他 AI 生成“教 AI 做事的方法和指令”

## 開發技巧

1）首先用 Agent 模式，貼上需求分析文案，讓 AI 自助生成網站，直到能夠執行

2）能夠成功執行後，進行測試，並且依次完成每個功能（這個階段需要不斷除錯）

## 需求分析

**一、目標使用者**

- 普通使用者: 關注自身健康狀況，希望瞭解自身肺功能水平。
- 健身愛好者: 監測訓練效果，評估心肺功能。
- 醫療機構: 輔助診斷呼吸系統疾病，跟蹤患者康復情況。

**二、核心功能**

1）【P0】肺活量測試。使用者根據提示進行吹氣，網站透過麥克風獲取資料。

2）資料視覺化: 實時顯示吹氣曲線、峰值流速、肺活量值等。

3）結果評估: 根據年齡、性別、身高、體重等生成肺活量指數，提供健康建議，比如運動、飲食等方面的建議。

4）儲存使用者測試記錄，生成歷史資料圖表，支援檢視趨勢圖。

5）提供健康小知識：可以檢視肺健康相關知識，如肺活量提升方法、呼吸系統疾病預防等。

6）社交分享: 支援使用者生成測試結果的分享卡片，可以儲存為圖片
