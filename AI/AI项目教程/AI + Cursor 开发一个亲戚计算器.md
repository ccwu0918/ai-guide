## 一、需求分析

親戚計算器：可以任意輸入親戚關係、得到一個計算結果

![img](https://pic.yupi.icu/yuyi/SSZhiv8c2hlFgbq1.webp)

### 需求分析 - AI 的思考

可以讓 AI 輔助需求分析，拓寬我們的想象力

**一、基礎功能升級：**

- **語音輸入/輸出（❌ 不做）：** 解放雙手，直接說出“我媽媽的姐姐的女兒是誰”，AI 自動識別關係並回答“你的表姐”。
- **方言支援 P1：** 識別不同地區對親戚的稱呼差異，例如“姥爺”和“外公”，“姑媽”和“姨媽”。
- **關係圖譜視覺化 P0：** 輸入一個名字，自動生成家族關係圖譜，清晰展示家族成員之間的關係。
- **親戚關係百科 P2：** 點選任意親戚關係，顯示該關係的詳細解釋、常見稱呼、風俗習慣等。

**二、趣味功能拓展（暫時不做）：**

- **親戚關係推理遊戲：** AI 給出一些線索，使用者猜測目標人物與自己的關係，例如“她是我媽媽的妹妹的女兒，但不是我表姐，她是誰？”。
- **親戚稱呼挑戰：** AI 隨機生成複雜親戚關係，使用者需要在限定時間內說出正確稱呼，挑戰你的反應速度和親戚知識儲備。
- **親戚關係預測（不錯）：** 輸入你和伴侶的生日，AI 預測你們未來孩子的親戚關係圖，例如“你的孩子將會有多少個表兄弟姐妹”。
- **親戚關係社交：** 連線家族成員，分享家族故事、照片、影片，記錄家族歷史，增強家族凝聚力。

**三、AI 增強功能（暫時不做）：**

- **智慧推薦稱呼：** 根據使用者輸入的關係，AI 自動推薦最合適的稱呼，避免稱呼不當的尷尬。
- **親戚關係分析：** AI 分析使用者的家族關係，識別出關繫緊密的親戚，並提供維護關係的建議。
- **家族基因預測：** 結合家族成員的健康資料，AI 預測使用者患某些疾病的風險，並提供預防建議。
- **家族文化傳承：** AI 根據使用者的家族歷史和文化背景，推薦相關的書籍、電影、音樂等，幫助使用者瞭解家族文化。

**四、其他創意功能（暫時不做）：**

- **親戚關係主題表情包：** 根據不同的親戚關係，生成一系列搞笑表情包，例如“被七大姑八大姨催婚的我”。
- **親戚關係主題濾鏡：** 開發一些與親戚關係相關的 AR 濾鏡，例如“變身成我的小姨”。
- **親戚關係主題遊戲：** 開發一些與親戚關係相關的小遊戲，例如“親戚連連看”、“親戚關係大冒險”等。

**目標使用者：**

- 對親戚關係感到困惑的年輕人
- 想要了解家族歷史的使用者
- 喜歡嘗試新鮮事物的使用者
- 想要增強家族凝聚力的使用者

### 最終要做的需求

1. 首先是能夠讓使用者在計算器上輸入親戚關係，最終給出答案
2. 輸出關係圖譜，更直觀地讓使用者瞭解親戚關係
3. 讓 AI 給出親戚的分析和計算過程

### 生成網頁的 Prompt

#### 自己寫的 Prompt

現在我要開發一個親戚計算器【網站】，要求實現如下需求：

1. 能夠讓使用者在計算器上輸入親戚關係，最終給出答案
2. 能夠輸出關係圖譜，更直觀地讓使用者瞭解親戚關係
3. 給出答案的分析和計算過程（每一個步驟都要講清楚）

要求：

1. 單頁面應用
2. 根據我給出的介面原型圖進行網站介面的開發

技術棧：HTML + CSS + JS

```markdown
▼markdown

複製程式碼**專案目標：**  
開發一個單頁面應用（SPA）的親戚計算器網站，使用者可以透過輸入親戚關係，獲取準確的親戚稱呼，並視覺化展示關係圖譜。同時，網站需提供詳細的計算過程分析，幫助使用者理解每一步的邏輯。

---

**功能需求：**  
1. **親戚關係計算功能：**  
   - 使用者可以透過輸入框或選擇器輸入親戚關係（例如：“我媽媽的妹妹的女兒”）。  
   - 網站能夠解析輸入的關係，並輸出正確的親戚稱呼（例如：“表妹”）。  

2. **關係圖譜視覺化：**  
   - 根據使用者輸入的關係，動態生成關係圖譜，以圖形化的方式展示家族成員之間的關係。  
   - 圖譜需支援縮放、拖拽等互動功能，方便使用者檢視複雜關係。  

3. **計算過程分析：**  
   - 在給出最終答案的同時，顯示詳細的計算步驟（例如：  
     - 第一步：“媽媽的妹妹” → 姑姑  
     - 第二步：“姑姑的女兒” → 表妹）。  
   - 每一步需附帶簡短的解釋，幫助使用者理解邏輯。  

---

**介面需求：**  
1. **單頁面應用（SPA）：**  
   - 所有功能集中在一個頁面內，無需跳轉。  
   - 頁面佈局簡潔，分為輸入區、結果展示區、關係圖譜區和計算過程分析區。  

2. **介面原型：**  
   - 根據提供的介面原型圖進行開發，確保佈局、配色、字型等與原型一致。  
   - 支援響應式設計，適配不同裝置（桌面、平板、手機）。  

---

**技術棧：**  
- **前端：** HTML + CSS + JavaScript  
- **視覺化庫：** 使用 D3.js 或類似庫實現關係圖譜的視覺化。  
- **互動邏輯：** 使用原生 JavaScript 實現動態互動。  

---

**其他要求：**  
1. **程式碼結構清晰：**  
   - 使用模組化程式設計，將計算邏輯、圖譜生成、UI 渲染等功能分離。  
   - 新增必要的註釋，便於後續維護和擴充套件。  

2. **使用者體驗最佳化：**  
   - 提供輸入示例或提示，幫助使用者正確輸入關係。  
   - 在使用者輸入錯誤時，給出友好的錯誤提示（例如：“無法識別的關係，請檢查輸入”）。  

3. **效能最佳化：**  
   - 確保圖譜渲染和計算過程流暢，避免卡頓。  

---

**示例輸入輸出：**

    2. “姑姑的女兒” → 表妹
```

## 四、擴充套件知識

目前純前端的親戚計算器透過列舉 + 遞迴實現，在親戚關係較複雜的情況下，難以給出準確的答案？

解決方案：可以透過呼叫後端，後端接入 AI，讓 AI 來給出親戚的分析結果。

進一步最佳化：但是純調後端又很費錢，針對能列舉的計算、直接呼叫前端；前端無法給出答案的情況，再呼叫後端。
