# 💗用 DeepSeek 給物件做個網站，她一定感動壞了

> 本文對應影片，觀看體驗更好哦：[https://bilibili.com/video/BV1NYKPebEyT](https://bilibili.com/video/BV1NYKPebEyT)

大家好，我是程式設計師魚皮。又是一年特殊的日子，作為一名程式設計師，總是幻想著自己有物件， 總是想著用自己賊拉牛 X 的程式設計技術給物件做個網站。



要是在以前，我會直接複製一個開源專案，然後修改程式碼把名稱改成自己的。像我幾年前就給大家分享過一個開源的表白網站原始碼：

![圖片](https://pic.yupi.icu/yuyi/640.png)

但現在有了 AI，這件事情不要太輕鬆！哪怕沒學過網站開發，照樣幾十秒搞定~

開啟咱們最近很火的 DeepSeek，輸入一句簡單的提示詞，比如：幫我寫一個網站，能夠展示 “祝 XXX 情人節快樂”。

**稍等片刻，奇蹟就出現了！**

那怎麼把做好的網站分享出去呢？

方法 1：很簡單，錄一段影片，然後發給她，她一定會很感動。

![圖片](https://pic.yupi.icu/yuyi/640.jpeg)

好吧，我們還是複製程式碼，然後貼上到一個文字編輯器中（用 Windows 自帶的記事本都 OK），儲存為 HTML 格式的檔案，最後把這個檔案發給她就行啦！她一定會很感動。

![圖片](https://pic.yupi.icu/yuyi/640-20250221181800502.jpeg)

坑爹的是，VX 裡是不能直接開啟 HTML 檔案的！所以還是要能線上訪問，才足夠有誠意啊。

我們開啟程式碼分享工具 `codepen`，建立一個程式碼筆記：

![圖片](https://pic.yupi.icu/yuyi/640-20250221181800550.png)

然後複製程式碼到 HTML 編輯框中，最後點選分享，就可以將得到的地址傳送給別人啦~

![圖片](https://pic.yupi.icu/yuyi/640-20250221181800603.png)

這樣一來，不需要自己搞伺服器，也能訪問到你的網站，這種套路非常適合小網站的開發。
