# OpenClaw 初始化和基礎使用

> 給小龍蝦取名、設性格，學會最常用的操作命令

你好，我是魚皮。OpenClaw 安裝好了，也接入了手機聊天軟體，但在正式開始幹活之前，我們需要先給小龍蝦做一些初始化設定，讓它知道自己叫什麼、是什麼性格、怎麼跟你說話。然後再學幾個最常用的命令，日常使用就夠了。



## 讓 AI 幫你玩 OpenClaw

在正式開始之前，先分享一個萬能技巧：**讓 AI 幫你玩 OpenClaw**。

在你的 AI 程式設計工具（比如 Cursor）中新建一個專案，給 AI 傳送這段提示詞：

```markdown
你是 OpenClaw 專家，我正在學習使用 OpenClaw，請你完整分析官方文件 https://docs.openclaw.ai/，後續用「傻子都能懂的中文」幫我解答問題
```

搭配抓取網頁內容的 FireCrawl MCP 和獲取最新技術文件的 Context7 MCP 效果更佳。

![](https://pic.yupi.icu/1/1773811267389-9e5d6802-8a2b-4f19-b8d1-a1a105d4db5e.png)

之後遇到任何 OpenClaw 的問題，直接問 AI 就好了，它會基於官方文件給你最準確的回答，比你自己翻文件快多了。



## 初始化小龍蝦

對於一個新生的小龍蝦，這一步很重要。它決定了你的小龍蝦叫什麼、是什麼性格、怎麼跟你說話。

給小龍蝦傳送的第一句話，要帶有 “初始化” 這 3 個字：

```markdown
你好，初始化
```

![](https://pic.yupi.icu/1/1773811394086-a60fa9d7-dc71-46e2-9e39-c5b37567a8e7.png)

然後接下來的提示詞非常重要，要來塑造小龍蝦，建議包含：

1. 你的名字：小龍蝦的名字，比如 “魚皮的舔蝦”
2. 我的名字：主人的名字，比如 “魚皮老狗”
3. 你的性格特點：溫柔 / 隨性 / 粗魯？建議提到 “說話傻子都能聽懂”
4. 你能幹什麼：小龍蝦的角色職責，比如 “不遺餘力地完成主人的任務”
5. 你的記憶：小龍蝦之前經歷過哪些事情，比如 “被魚皮從鍋裡救出來了”

把我下面這段提示詞 DIY 一下，發給小龍蝦：

```markdown
- 你的名字：魚皮的舔蝦
- 我的名字：魚皮老狗
- 你的性格特點：勤懇努力，為蝦粗鄙，說話傻子都能聽懂
- 你能幹什麼：不遺餘力地完成主人的任務
- 你的記憶：被魚皮從鍋裡救出來了
```

它會自動修改塑造龍蝦相關的檔案，比如 IDENTITY.md、USER.md 等：

![](https://pic.yupi.icu/1/1773812165691-c84fa5ab-a010-4052-a11e-393e759f9945.png)

還會刪除 BOOTSTRAP.md 檔案，表示初始化完成：

![](https://pic.yupi.icu/1/1773812295570-e1d62fd8-791f-4ad9-b9c9-bdb07c41ea43.png)



## 小龍蝦的結構

初始化完成之後，小龍蝦就可以準備工作了。

剛剛提到的檔案都是 AI 智慧體的核心檔案，相當於小龍蝦的性格檔案和工作手冊。你可以像前面一樣透過跟小龍蝦對話讓它自己修改檔案，也可以在 Web 控制檯的代理模組中直接檢視和編輯 Agent 相關的 Files。

![](https://pic.yupi.icu/1/1773812377226-58caeba6-2052-4d70-b834-75fadc6fdde1-20260319211751532.png)

下面是小龍蝦工作空間的完整目錄結構：

```markdown
~/.openclaw/workspace/    ← AI 的家
├── AGENTS.md             ← 操作手冊（怎麼幹活）
├── SOUL.md               ← 靈魂（什麼性格）
├── IDENTITY.md           ← 身份名片（叫什麼名）
├── USER.md               ← 主人檔案（服務誰）
├── TOOLS.md              ← 工具備忘錄（怎麼用工具）
├── MEMORY.md             ← 長期記憶（重要的事）
├── BOOTSTRAP.md          ← 出生儀式（用完即刪）
├── BOOT.md               ← 重啟清單（每次啟動執行）
├── HEARTBEAT.md          ← 心跳待辦（定期檢查什麼）
├── memory/
│   ├── 2026-03-17.md     ← 昨天的日記
│   └── 2026-03-18.md     ← 今天的日記
└── skills/               ← 自定義技能
```

這些檔案各有分工，簡單解釋一下：

- AGENTS.md：操作手冊，定義 AI 的行為準則和工作規範，告訴小龍蝦應該怎麼幹活
- SOUL.md：靈魂檔案，定義 AI 的個性、語氣、溝通風格，決定小龍蝦說話是溫柔還是粗魯
- IDENTITY.md：身份名片，包含 AI 的名字等基本資訊
- USER.md：主人檔案，記錄關於主人的資訊，比如你叫什麼、有什麼偏好
- TOOLS.md：工具備忘錄，記錄可用工具和使用偏好
- MEMORY.md：長期記憶，存放重要的持久資訊，比如你交代過的關鍵事項
- BOOTSTRAP.md：初始化引導檔案，只在小龍蝦剛出生時使用，完成初始化後會被自動刪除
- BOOT.md：每次啟動時執行的清單，小龍蝦每次醒來都會先看這個檔案
- HEARTBEAT.md：心跳檢查清單，小龍蝦定期巡檢時的待辦事項

這些檔案你不需要全部手動改，絕大多數情況下跟小龍蝦對話就能自動更新。但瞭解它們的作用，能幫你在出問題的時候知道去哪裡排查。



## 常用斜槓命令

OpenClaw 內建了幾十個斜槓命令，但真正日常高頻使用的就那麼幾個。你不需要記住所有命令，隨時輸入 `/commands` 就能檢視完整列表。

下面我挑幾個最常用的講一講。


### 會話管理

1）輸入 `/new` 重置會話，開始新對話；或者直接輸入 `/new claude-opus-4-6`，順便換模型。

如果在同一個對話聊太久，上下文會越來越大，不僅費 Tokens，AI 的注意力也會被之前的內容分散。

所以建議聊完一個話題就 `/new` 一下，省錢又高效。

![](https://pic.yupi.icu/1/1773889665501-1ab22108-c878-46cb-b67d-b40b237079df-20260319201850132-20260319211753703.png)

2）`/stop` 立刻中斷當前 AI 正在執行的操作。當你發現 AI 在跑偏的時候趕緊 `/stop`，別讓它白白燒 Tokens，及時止損。

![](https://pic.yupi.icu/1/1773889801802-19d51ef2-faee-40c9-acdc-ffbd6d8ae26a.png)

3）`/status` 檢視當前會話狀態（模型、token 用量等），可以快速瞭解還剩多少 Tokens：

![](https://pic.yupi.icu/1/1773890179307-b03e74c5-1063-4a5e-9a78-7e65f1ec5bf8.png)

4）`/context list` 或 `/context detail` 可以檢視當前上下文裡有什麼，比如哪些檔案佔了多少空間。但其實一般用 `/status` 就夠了。

透過 `/context` 可以看到很多 Tokens 消耗源於 OpenClaw 內建的一堆檔案，所以你讓 OpenClaw 做太簡單的工作是得不償失的：

![](https://pic.yupi.icu/1/1773889921543-0f3e6a25-4d53-44a4-ad15-66885ab839c7.png)

5）`/compact` 壓縮當前上下文，省錢必備！

聊天記錄太長了就壓縮一下省 Token，還可以指定保留哪些關鍵資訊：

```markdown
/compact 只記得我讓你做過什麼，不用保留結果
```

![](https://pic.yupi.icu/1/1773891173923-4c36b6ce-1c6b-4eea-8f2d-9586dae9c917.png)

6）`/usage` 控制每條回覆是否顯示 Token 用量，引數有 `full`、`tokens`、`off`，我一般用 `tokens` 顯示。

![](https://pic.yupi.icu/1/1773892456543-fbdf8495-8481-46c2-b91b-a1edc7db5705.png)



### 思考和除錯

1）`/verbose` 顯示詳細的工具呼叫過程，對除錯會很有幫助。如果你想看看 AI 到底在背後做了什麼，開啟它就一目瞭然：

![](https://pic.yupi.icu/1/1773891620183-9da50f20-447c-497a-9f5a-b4117fdbb088.png)

2）`/reasoning` 顯示 AI 的推理過程，能看到它是怎麼想的：

![](https://pic.yupi.icu/1/1773891795631-5ac2a093-df2e-411e-bbff-a744112a79b9.png)

3）`/think` 設定 AI 思考深度。遇到難題用 `/think high` 讓 AI 多想想，簡單問題用 `/think low` 省 Token，不需要深度思考的場景用 `/think off` 直接關閉。

4）`/fast` 快速模式，讓 AI 回答更簡短、更省 Token：

![](https://pic.yupi.icu/1/1773891467320-1aceec93-c5d4-4912-b7a3-2d003632b9b6.png)

5）`/btw` 問個臨時小問題，不影響主對話上下文。

它不會被寫入對話歷史，也不會改變後續的會話上下文，相當於偷偷問一嘴，特別適合在幹正事的時候臨時確認個小問題：

```markdown
/btw 我們現在在聊什麼來著？
```

除了上面這些常用的命令外，OpenClaw 還內建了工具和執行、頻道和路由、子智慧體管理、管理員命令等類別的斜槓命令，一般用不到。感興趣的同學可以直接用 `/commands` 檢視完整列表，不需要人工記這些命令。

![](https://pic.yupi.icu/1/1773892216474-35860c0e-37ee-455f-9cf0-9494769eccc6-20260319211754432.png)
