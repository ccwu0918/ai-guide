# OpenClaw 定時任務與自動化

> 讓小龍蝦定時幫你巡檢、彙報、備份

你好，我是魚皮。前面我們學了怎麼跟小龍蝦對話讓它幹活，但每次都要手動發訊息未免太累了。OpenClaw 提供了多種自動化機制，讓小龍蝦自己按時幹活，你只需要定好規則就行。



## 定時任務（Cron）

定時任務（Cron）就是讓小龍蝦在指定的時間或固定間隔，自動執行你交代的任務，不需要你手動提醒。

定時任務支援標準的 Cron 表示式，也支援自然語言描述。你不用懂什麼 Cron 語法，直接跟小龍蝦說人話就行。

比如我讓小龍蝦：

```markdown
每隔 5 分鐘，給我輸出 codefather.cn 網站的執行狀態，以及最新發布的帖子。
```

相當於給我的網站增加了一個 24 小時值班的巡檢員：

![](https://pic.yupi.icu/1/1773914794167-a54098af-b73b-474d-acf5-d807644fda9d.png)

可以在 OpenClaw 網頁控制檯檢視和管理已建立的定時任務：

![](https://pic.yupi.icu/1/1773914857729-162eab56-8c92-41f0-8ae3-e75eef18d5d7.png)

定時任務的執行日誌也能在 Web 控制檯檢視，出了問題方便排查。

除了跟小龍蝦對話建立定時任務外，也可以直接在上面的介面新建任務，或者透過終端命令列 `openclaw cron add` 建立（詳見 [官方 Cron 文件](https://docs.openclaw.ai/automation/cron-jobs) ）。

但我不建議用這些方式，還得填寫一堆引數資訊，這不折磨自己嘛？跟龍蝦說一嘴就搞定了。

除了網站監控之外，定時任務還有很多貼近日常生活的用法，隨便列舉幾個：

- 每天早上 8 點傳送今日待辦提醒
- 每天晚上 10 點總結當天的聊天重點並寫入記憶
- 每週一早上 9 點生成上週工作總結
- 定時檢查你關注的 GitHub 專案有沒有更新
- 定期備份重要檔案到指定目錄
- 每天中午 12 點抓取某個網站的資料並整理成表格
- 每週五下午自動生成本週學習筆記



## 心跳（Heartbeat）

心跳（Heartbeat）是 OpenClaw 內建的另一種定時機制。

它和定時任務的區別在於：定時任務是你明確告訴小龍蝦 **在某個時間做某件具體的事**，而心跳是小龍蝦每隔一段時間自己醒來看一眼 **有沒有什麼需要注意的**，更像是一種被動巡邏。

心跳預設每 30 分鐘執行一次，你可以透過配置調整間隔。心跳會讀取工作空間中的 `HEARTBEAT.md` 檔案作為檢查清單，如果沒什麼事就靜默跳過（返回 `HEARTBEAT_OK`），有事才會通知你。

配置心跳間隔的命令：

```bash
openclaw config set agents.defaults.heartbeat.every "30m"
```

如果你覺得心跳沒用，想關掉它：

```bash
openclaw config set agents.defaults.heartbeat.every "0m"
```

對個人使用者來說，一般用不到心跳機制，定時任務已經足夠覆蓋大多數場景了。如果你想深入瞭解心跳和定時任務的區別，可以參考官方文件：https://docs.openclaw.ai/automation/cron-vs-heartbeat



## 進階自動化

除了定時任務和心跳，OpenClaw 還有幾個更高階的自動化功能。大多數人根本用不到，這裡簡單介紹一下，感興趣的同學去看官方文件就好。

**Hooks 鉤子自動化**

讓你的 OpenClaw 在關鍵節點自動做一些事，比如每次開新對話時自動儲存上下文、每次執行命令時自動記日誌、啟動時自動載入額外配置檔案。相當於給 AI 的工作流加了 “自動觸發器”，某個事件一發生就自動執行對應的動作。參考官方文件：https://docs.openclaw.ai/automation/hooks

**Webhook 和外部整合**

可以把 OpenClaw 和其他服務打通。比如收到 GitHub Issue 時自動通知龍蝦處理、接收外部系統的事件推送等。如果你用過飛書機器人或者 Slack 的 Webhook，這個概念是類似的。參考官方文件：https://docs.openclaw.ai/automation/webhook

**Lobster 工作流引擎**

用於多步驟工具管道的確定性執行，支援暫停、審批、恢復等流程控制。簡單來說就是當你的自動化任務需要人工審批環節時（比如 AI 寫完程式碼後等你確認再提交），可以用 Lobster 來編排這種多步驟工作流。參考官方文件：https://docs.openclaw.ai/tools/lobster
