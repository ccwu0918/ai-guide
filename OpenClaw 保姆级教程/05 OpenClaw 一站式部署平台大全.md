## 雲端部署 - 24 小時養龍蝦

如果你想讓 OpenClaw 7×24 小時線上、隨時隨地透過手機遙控它幹活，那就需要一臺雲伺服器。

目前國內各大雲廠商基本都推出了 OpenClaw 一鍵部署方案，競爭只能用「慘烈」來形容。為了讓大家選擇自家伺服器來部署龍蝦，真是各出奇招。

- 百度智慧雲：推出了 DuClaw 零部署方案，訂閱後直接用，不用自己選映象配 API Key，搭配 Coding Plan 組合價首月 17.8 元
- 騰訊雲：輕量應用伺服器預置 OpenClaw 映象，一鍵部署，最低一年幾十塊
- 阿里雲：輕量應用伺服器 + 百鍊 API，一鍵配置，9.9 可以用一個月
- 華為雲：9.9 元養蝦，還贈送千萬 Tokens
- 火山引擎：推出 ArkClaw 雲端 SaaS 版，深度整合飛書，新使用者可以搶首月 8.9 元的機會
- 京東雲：支援一鍵部署，9.9 可以用一個月

值得一提的是，京東雲還搞了個「養數字龍蝦，送真龍蝦」的免費安裝 OpenClaw 活動。使用者完成 OpenClaw 安裝部署並完成一次任務執行，現場送出美味小龍蝦！

## 本地桌面端 - 零門檻養龍蝦

雲端雖好，但畢竟要花錢。如果你只是想先體驗一下、或者不想資料上雲，本地桌面端才是真正的零門檻方案。

只要下載安裝包、雙擊安裝，龍蝦就出生了~

目前已經有好幾款成熟的桌面端產品，我挨個給大家介紹一下。



### 1、騰訊 QClaw

騰訊電腦管家團隊出品，最大的殺手鐧是微信直連。

安裝完掃個碼，就能在微信裡直接給 AI 發訊息讓它幹活。內建了 Kimi-2.5 等國產模型、5000+ 技能，內測期間完全免費。

目前 Mac 版和 Windows 版都已開放下載，不過還處於內測階段，需要先填寫問卷申請邀請碼，稽核透過後會透過簡訊發放。

> 指路：https://claw.guanjia.qq.com
>
> 內測申請：https://wj.qq.com/s2/25871229/abe7

![](https://pic.yupi.icu/1/image-20260314140352682.png)

對於普通使用者來說，微信就是最自然的入口，老人小孩都能用，這一點是騰訊天然的優勢。



### 2、智譜 AutoClaw

智譜 AI 出品，內建自家深度最佳化的 GLM 模型，預置了 50+ 熱門技能，支援多步驟、跨頁面的複雜網頁操作。特別適合需要自動填表、自動爬資料、自動操作網頁的場景。

> 指路：https://autoglm.zhipuai.cn/autoclaw

![](https://pic.yupi.icu/1/image-20260314140608293.png)



### 3、獵豹 EasyClaw

獵豹移動出品，走極簡路線。最大特點是免配置、免 API Key，雙擊安裝直接就能用。

和其他桌面端不同的是，EasyClaw 內建了多款頂級大模型（包括 GPT、Claude、Kimi 等），由獵豹官方代付模型費用，使用者不需要自己註冊任何模型服務商的賬號或填寫 API Key。

個人使用者完全免費，超輕量不佔記憶體，適合只想簡單跑起來不折騰的同學。

> 指路：https://easyclaw.cn

![](https://pic.yupi.icu/1/banner.png)



### 4、騰訊 WorkBuddy

騰訊的另一款產品，定位比 QClaw 更偏企業辦公場景。

> 指路：https://www.codebuddy.cn/work

![](https://pic.yupi.icu/1/image-20260314141108260.png)

嚴格來說它不是 OpenClaw 的套殼，而是底層自研但完全相容 OpenClaw 技能包。支援企業微信、QQ、飛書多平臺遙控，內建混元、DeepSeek、GLM、Kimi 等多款模型可切換，新使用者送 5000 Credits。

![](https://pic.yupi.icu/1/image-20260314142502149.png)



### 5、網易有道 LobsterAI

網易有道出品，國內大廠中首個開源的桌面級 AI Agent。

支援本地直接執行或 Alpine Linux 沙箱隔離執行，安全性比較好。內建 16 種核心技能（包括 Office 文件生成、Web 搜尋、Playwright 自動化等），支援 DeepSeek、Qwen 等模型自由切換，還能透過企微、QQ、釘釘、飛書遠端控制。

> 指路：https://lobsterai.youdao.com

![](https://pic.yupi.icu/1/image-20260314141259527.png)

程式碼在 GitHub 上完全開源，適合想研究底層原理的開發者。

> 倉庫指路：https://github.com/netease-youdao/LobsterAI

![](https://pic.yupi.icu/1/image-20260314141221546.png)

社群維護的中文桌面客戶端，圖形化介面配置，支援 20+ AI 模型接入，免費使用。

如果你不想用任何大廠的封裝產品、想要原汁原味的體驗，可以選這個（不過目前不支援 macOS 版）。

> 指路：https://openclawcn.net

## 如何選擇？

如果你只是想嚐嚐鮮、體驗一下 AI 幫你幹活的感覺，QClaw、AutoClaw、EasyClaw 這些本地桌面端隨便挑一個，雙擊安裝就能玩，一分錢不花。

如果你想讓 OpenClaw 24 小時線上、當你的全天候 AI 員工，那就需要一臺雲伺服器。好在現在各家基本都是一鍵部署、不需要程式設計基礎，滑鼠點幾下就能搞定，而且價格也都捲到了個位數。

如果你在企業裡用、需要多人協作和多平臺遙控，WorkBuddy 是合適的選擇。它本身就是騰訊面向職場場景設計的，支援企微、QQ、飛書多端操控，而且相容 OpenClaw 的技能生態。

如果你是開發者、想研究底層原理或者做二次開發，LobsterAI 是首選，它是國內大廠中首個以 MIT 協議開源的桌面級 AI Agent，程式碼可以直接在 GitHub 上拉取。

對了，如果你是硬核玩家，Mac Mini、群暉 NAS、甚至樹莓派都能跑 OpenClaw，實現 24 小時本地執行。不過對於大多數人來說，上面這些桌面端產品已經完全夠用了。
