### 開放平臺

除了可以在網頁上使用魚聰明外，魚皮本身作為程式設計師，當然也考慮到了程式設計師朋友們的需求啦。

所以我們提供了開放平臺，讓你在程式中使用 AI 助手！

![](https://pic.yupi.icu/5563/202404191333108.png)

只需要使用我們開源的 SDK（工具程式碼），就能輕輕鬆鬆，只用幾行程式碼使用 AI 助手能力！

示例程式碼如下，可以選擇要使用的助手：

```Plain
// 構造請求
DevChatRequest devChatRequest = new DevChatRequest();
devChatRequest.setModelId(1651468516836098050L);
devChatRequest.setMessage("魚皮");
// 獲取 AI 助手的回覆
BaseResponse<DevChatResponse> response = client.doChat(devChatRequest);
System.out.println(response.getData());
```

由於我們目前人力有限，所以只能先提供 Java SDK，大家如果感興趣的話，歡迎貢獻其他語言的 SDK 哦~
